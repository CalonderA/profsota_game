# 🎮 Шахта Знаний · СОТА

> Профориентационный симулятор производственной практики для абитуриентов и студентов **ОГБПОУ «Смоленская областная технологическая академия» (СОТА)**.

## 📁 Архитектура проекта

Проект разделен на изолированные модули, чтобы члены команды могли разрабатывать свои направления без конфликтов в Git.

```text

├── serve.js / serve.ps1         # Локальные HTTP-серверы (Node.js или PowerShell)
```

## 🚀 Запуск симулятора

1. Запустите файл `start.bat` двойным кликом.
2. Скрипт автоматически поднимет локальный сервер на `http://127.0.0.1:8787/` и откроет главное меню в браузере.
   - Если установлен **Node.js**, используется `serve.js`.
   - Если Node.js не установлен, автоматически запускается встроенный PowerShell-сервер `serve.ps1`.

## 🛠 Руководство для команды: Как добавить / изменить специальность

Каждое направление находится в отдельной папке `specialties/<имя>/`:
- Например, для специальности **«Э» (Электрооборудование)**:
  - Папка: `specialties/e/`
  - Разметка экранов мини-игры: `specialties/e/index.html`
  - Стили: `specialties/e/e.css`
  - Код мини-игры и станка: `specialties/e/e.js`

### Регистрация собственной мини-игры в общем движке:
В файле `specialties/<название>/<название>.js`:
```javascript
// 1. Регистрация мини-игры между сменами
window.registerMinigame('my_minigame_id', {
  name: 'название мини-игры',
  start: startMyMinigame,
  cleanup: cleanupMyMinigame
});

// 2. Отрисовщик станка в 2.5D цеху
window.registerStationRenderer('e', function(type, done, hard, now, seed) {
  // Рисование на ctx холста 2.5D
});
```

Вам **не нужно** редактировать файлы ядра (`shared/`) или файлы других участников команды.
Все изменения изолированы в папке вашей специальности, что предотвращает конфликты слияния в Git!

- **Векторный файл**: `assets/sota_hexagons.svg`
- **Прозрачный растровый файл**: `assets/sota_hex_clean.png`
- **Шапка**: Брендовый значок СОТА и наименование «Шахта Знаний» зафиксированы в верхнем левом углу на всех страницах проекта.
