# Шахта Знаний

Для запуска нужен Node.js. Откройте `start.bat` или выполните `node serve.js`.

## Совместная игра

1. Запустите сервер на одном компьютере.
2. На компьютере откройте `http://127.0.0.1:8787/` и нажмите **Играть вместе**.
3. На других устройствах в той же Wi-Fi сети откройте сетевой адрес, напечатанный сервером, например `http://192.168.1.10:8787/`, и тоже нажмите **Играть вместе**.

Все автоматически попадают в одну общую шахту, без кода комнаты. Игра рассчитана только на совместное прохождение, от двух до восьми участников. Пока второго игрока нет, движение и расход света приостановлены. Если товарищи выходят, оставшийся игрок ждёт подключения второго участника. Вопрос решает игрок, подошедший к кристаллу; остальные могут исследовать шахту. Кристаллы и переход к следующей шахте общие, очки, силы и фонарь — у каждого свои. Переход у лестницы переносит всю команду. Поход начинается из Кардымова и состоит из двух шахт.

На маленьких экранах товарищей видно на мини-карте. Позднее подключение присоединяет к текущему походу. При выходе всех игроков общая игра сбрасывается. Одиночного режима нет.

Для доступа с телефона компьютеру и телефону нужна одна сеть, а входящий TCP-порт 8787 должен быть доступен. Адрес `127.0.0.1` работает только на самом компьютере. Для игры через интернет потребуется сервер с доступным внешним адресом; текущий запуск рассчитан на локальную сеть. Состояние хранится в памяти и сбрасывается при перезапуске сервера.

## Публикация на Vercel

Локальный `serve.js` не является обработчиком запросов Vercel. Для сайта используется функция `api/coop.js` и общее хранилище Redis: память отдельных экземпляров функции не объединяется.

1. В настройках проекта Vercel выберите Framework Preset **Other**; не задавайте отдельный каталог вывода и команду сборки. Опубликуйте репозиторий с `api/coop.js`, `server/` и `vercel.json`.
2. В Vercel Marketplace подключите **Upstash Redis** к этому проекту и окружению Production.
3. Проверьте наличие серверных переменных `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN`. Поддерживаются также `KV_REST_API_URL` и `KV_REST_API_TOKEN`. Секреты не добавляются в HTML или Git.
4. Выполните **Redeploy**. Затем два игрока открывают один адрес сайта и нажимают **Играть вместе**. Одна Wi-Fi сеть для опубликованного сайта не требуется.

При общем хранилище для нескольких окружений задайте разные `COOP_STORAGE_KEY`, например `profsota:production` и `profsota:preview`, чтобы игроки тестового и основного сайтов не смешивались. Состояние неактивной сессии удаляется через две минуты. Одновременные изменения сохраняются атомарно, с повтором при конфликте.

Если функция или хранилище не настроены, страница покажет понятную ошибку вместо `Unexpected token`.

Проверки: `npm test`.
